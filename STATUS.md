# Stav portálu

Aktualizováno: 2026-09-04

Portál je aktivní produkční software. Git pracovní strom byl při dokumentační
adopci čistý a funkční zdroj zůstal nezměněný. Aktuální produkční dostupnost,
auth a E2E nebyly před zápisem dokumentace prohlášeny za čerstvě ověřené.

Operativní práce nemá aktivní kartu. Další bezpečný krok je převzít jeden
schválený task, zachytit výchozí relevantní E2E a vymezit, zda změna zasahuje
UI, Functions, data, offline nebo autentizaci.
